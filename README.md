# Fantasy Tinker _(Temp project name)_
## The goal of this project is to create a cozy fixing game with a fantasy element.

### <ins>Current Project Status:</ins> Doing POC

### POC #1: Full 2D, Focused On Fixing 
This version will be done using full 2D and have only a fixing element to test the look and feel.

The fixing element includes:
- Disassemble the item component
- Reassemble the component
- Cleaning up the component
- Replacing the component
- Finding the matching component
